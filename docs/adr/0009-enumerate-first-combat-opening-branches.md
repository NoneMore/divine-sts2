# Enumerate legal opening branches for first-combat coverage

The first-combat generator's earlier one-row-per-offered-Ancient-choice contract is superseded: a character, Ascension, and run seed may produce multiple scenarios by taking different legal Ancient and nested choices. It enumerates non-skip choices and avoids obviously equivalent choices before branching, such as selecting interchangeable copies of the same card; it does not require a semantic comparison pass over completed rows, and keeps scenarios from different seeds even when their visible content matches. For removal or transformation, when a card model has both ordinary and upgraded or enchanted copies available, only an ordinary copy is explored. The omitted variant choice can lead to a distinct, reachable scenario; we accept that loss because it is expected to overlap existing corpus content more often.

This increases the value of each seed for character-card coverage at the cost of variable row counts, potentially expensive branching, and some equivalent output rows. We accept that cost initially and will consider restricting legal reward order for `NeowsBones` only if measured branch frequency warrants it; every retained recipe still obeys ADR-0003's shipped-game reachability requirement. Corpus summaries report row counts and coverage by content type, without claiming an exact global count of distinct NoSL scenarios.
