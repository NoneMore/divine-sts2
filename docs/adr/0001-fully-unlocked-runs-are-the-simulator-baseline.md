# Progression-complete runs are the project baseline

Every simulator and full-app sandbox run uses one progression-complete baseline: all progression unlock, content discovery, epoch, and tutorial gates are complete, while character, run seed, and Ascension remain configurable. Progression and discovery are not public run inputs; the simulator represents their gameplay effects directly, while a full-app sandbox materializes deterministic isolated progress data modeled on the shipped game's completion operations. Achievements, career totals, existing saves, the player's real profile, and multiplayer remain outside this baseline.

This replaces the earlier distinction between a fully unlocked run and an undiscovered profile. In particular, every Act is already discovered, so the shipped game's first-discovery override cannot replace the Act variant selected from the run seed; the simulator and shipped-game oracle therefore share the same content-complete distribution without carrying profile progression as simulation state.
